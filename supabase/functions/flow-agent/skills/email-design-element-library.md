# Email Design Element Library

These are not standard email sections. These are visual design elements, essentially static ad
creatives embedded within emails. They make emails skimmable, visually interesting, and varied.

The goal: a reader should be able to skim the email, never read a single body paragraph, and
still absorb 80% of the message through these visual elements alone.

Think of each element as a self-contained graphic that a designer builds as its own asset.
It lives inside the email but functions like a mini infographic, a carousel card, or an Amazon
product image. When you spec one of these in a copy doc, label it clearly so the designer
knows exactly what to build. The copy you write for each element is minimal and structured to
fit the visual format.

## Comparison & Contrast Elements

These elements put two things next to each other and let the contrast do the selling.
Extremely skimmable. The reader processes the comparison in 2 seconds without reading anything.

### Us vs Them Split Card

A side-by-side card, often with contrasting colors (dark/light, brand color/gray). One side
is the old way, the other is your product. Works as a standalone visual block.

```
Copy elements:
  Left column header: "Regular [Category]" or "Without [Product]" (2-4 words)
  Right column header: "[Brand Name]" or "With [Product]" (2-4 words)
  Per row (3-6 rows):
    Left: Negative point (3-8 words)
    Right: Positive point (3-8 words)

Design note: Contrasting background colors per column. Left side muted/negative, right side
brand color or bright. Keep rows parallel in structure. Each row should mirror.
```

### Before/After Photo Grid

Two photos side by side with "Before" and "After" labels. Can be product results, skin
changes, water clarity, anything visual. The photos ARE the content. Copy is just labels.

```
Copy elements:
  Left label: "Before" or "Without [Product]" (1-3 words)
  Right label: "After" or "With [Product]" (1-3 words)
  Caption: Optional. 1 sentence below the grid. (under 15 words)

Design note: Photos should be same angle, same lighting, same framing. The only variable
is the result. Can be a single before/after pair or a 2x2 grid of multiple results.
```

### Comparison Table

A structured data table comparing your product against alternatives across specific metrics.
Numbers or short phrases in each cell. No paragraphs.

```
Copy elements:
  Column headers: Product/category names (1-3 words each, 3-5 columns)
  Row labels: Metrics being compared (2-5 words each, 4-8 rows)
  Cell values: Numbers, short phrases, or checkmarks

Design note: Brand column highlighted with color. This is an infographic, not an HTML table.
Designer builds it as a graphic. Think Amazon comparison chart or supplement facts panel.
```

### Feature Checklist Matrix

A grid with checkmarks and X marks comparing your product against competitor categories.
Ultra-skimmable. The reader just sees a column of green checks vs a column of red X marks.

```
Copy elements:
  Column headers: Category names (1-3 words each, 3-5 columns)
  Row labels: Features/benefits being compared (3-6 words each, 5-8 rows)
  Cell values: Checkmark or X (or equivalent)

Design note: Build as a graphic, not a live table. Brand column gets all checks. Competitor
columns get a mix. The visual pattern of checks vs X marks tells the story instantly.
```

### Harsh vs Filtered Split (Contrast Detail Card)

A dramatic two-panel card where each side lists characteristics with mini-descriptions. More
detailed than Us vs Them. Each point gets a short expansion.

```
Copy elements:
  Left panel header: Negative framing (2-5 words)
  Right panel header: Positive framing (2-5 words)
  Per row (3-5 rows):
    Left header: Problem point (3-6 words)
    Left body: 1 short sentence expanding the point
    Right header: Solution point (3-6 words)
    Right body: 1 short sentence expanding the point

Design note: Strongly contrasting colors. Left side harsh/dark, right side clean/bright.
Often uses brand accent color on the positive side. Built as a single graphic card.
```

## Data & Proof Elements

These elements use numbers, charts, and data visualizations to build credibility. They function
like infographic snippets embedded in the email.

### Stat Callout Card

A single bold number or percentage, oversized, with a short label below. The number IS the
visual. It dominates the card.

```
Copy elements:
  Stat: The number. "10,000+", "83%", "4.9/5", "24/7" (1-5 characters)
  Label: What the number means. (3-8 words)

Design note: The number should be 40-72px. It's the hero of this element. Label sits
underneath in small type. Can be a single card or a row of 2-4 stat cards.
```

### Stat Strip (Multi-Stat Row)

A horizontal row of 2-4 stats. Each stat is a big number with a small label. Quick trust
injection without taking up a full section.

```
Copy elements:
  Per stat (2-4):
    Value: The number (1-5 characters)
    Label: What it means (2-5 words)

Design note: Even spacing across the email width. Thin dividers between stats optional.
This functions as a visual break between sections, not a section itself.
```

### Impact Bar Chart

Horizontal percentage bars showing relative impact or breakdown. Each bar has a label and
a percentage. Extremely visual, zero reading required.

```
Copy elements:
  Section header: Framing question or statement (3-8 words)
  Per bar (3-6 bars):
    Label: What's being measured (2-5 words)
    Percentage: The number (e.g., "100%", "35%", "15%")

Design note: Bars are filled to their percentage. Use brand color for the fill. Labels sit
left of or above each bar. This is an infographic element, not a text list.
```

### Line Graph / Trend Visual

A simple line graph showing change over time. Before vs After. Week 1 vs Week 4. The visual
trend tells the story. Minimal copy.

```
Copy elements:
  Title: What's being measured (3-8 words)
  X-axis labels: Time points (2-4 labels)
  Y-axis labels: Optional metric labels
  Caption: Optional. 1 sentence below. (under 15 words)

Design note: Build as a graphic. Simple, clean, one or two lines max. Not a complex chart.
The visual slope tells the story. Often used for "results over time" narratives.
```

### Nutrient / Spec Breakdown Table

A product data table showing specific ingredient amounts, nutrient values, or specs. Think
supplement facts panel or product spec sheet.

```
Copy elements:
  Product name: What product this table is for (1-4 words)
  Per row (4-8 rows):
    Metric: What's being measured (1-4 words)
    Value: The amount (number + unit)

Design note: Clean, minimal table design. Often on a dark or contrasting background. Can
include highlighted rows for standout values. Built as a graphic.
```

## Product Showcase Elements

These elements display products in visually interesting ways beyond a standard product image.

### Product Variant Grid (2x2 or 2x3)

A grid of product variants, flavors, or SKUs. Each cell is an image with a short
label. Shoppable visual. Minimal copy.

```
Copy elements:
  Per product (4-6):
    Label: Variant name (1-3 words)

Design note: Equal-sized product images in a grid. Can include price below each label.
This is a visual catalog element, not a text list with descriptions.
```

### Product Feature Icon Row

A row of 3-5 icons with short labels representing key product features or benefits. Think
Amazon bullet point icons or product packaging callouts.

```
Copy elements:
  Per feature (3-5):
    Icon description: What icon to use (for designer)
    Label: Feature name (2-5 words)

Design note: Icons should be simple, consistent in style. Circular backgrounds or line
icons. Even spacing. This is a trust strip, not an educational section.
```

### Benefit Grid (2x2 Icon Grid)

A 2x2 grid of icons with benefit labels. Each quadrant gets an icon and a short label.
No descriptions needed. Pure visual scanning.

```
Copy elements:
  Per benefit (4):
    Icon description: What icon to use
    Label: Benefit phrase (2-4 words)

Design note: Icons larger than in a feature row. Each quadrant is its own visual beat.
White space between quadrants. Labels centered under icons.
```

### "What's In the Box" Unboxing Visual

A flat-lay style element showing everything included in an order or bundle. Each item is
labeled with a callout line pointing to it.

```
Copy elements:
  Section header: "What's inside" or similar (2-5 words)
  Per item (3-6):
    Label: Item name (2-5 words)

Design note: Products arranged on a clean background with callout lines and labels.
Functions like product photography with annotations.
```

### Bundle / Value Stack Card

Shows everything the customer gets in one visual, often with individual prices crossed out
and a bundle price shown. Creates perceived value.

```
Copy elements:
  Header: "Everything you get" or offer framing (3-8 words)
  Per item (3-6):
    Item: What's included (2-6 words)
    Value: Individual price or value
  Total value: Combined value crossed out
  Your price: Actual price or "FREE with subscription"

Design note: Built as a single card. Strikethrough prices for individual items. Big
contrast between total value and actual price. Gift/bonus items flagged visually.
```

### Product Card Stack (Feature Cards)

3-4 bordered cards stacked vertically, each highlighting one product feature or sub-product.
Each card has a bold header and short description. Think product page feature blocks.

```
Copy elements:
  Per card (3-4):
    Header: Feature or product name (3-7 words)
    Body: 1-2 sentences. What it does or why it matters.

Design note: Each card has defined borders or background. Stacked vertically with even
spacing. Can include small icons or images per card. Clean, structured feel.
```

## Social Proof Elements

These elements let customers and third parties do the talking through visual formats.

### Review Card (Single Highlight)

A single review styled as a standalone card. Stars, pull quote, body, attribution. Designed
as a graphic, not inline text.

```
Copy elements:
  Stars: Star rating (typically 5)
  Pull quote header: Most powerful phrase (4-10 words, bolded)
  Body: The review text (1-3 sentences, raw/authentic)
  Attribution: Name + credential

Design note: This is a CARD with defined borders, background, or shadow. Not inline text.
It should feel like a standalone graphic, like a screenshot of a review.
```

### Review Carousel / GIF Block

3-5 reviews displayed as an animated sequence or overlapping card stack. Creates a sense
of volume and momentum.

```
Copy elements:
  Per review (3-5):
    Body: 1 sentence. Ultra-short. Under 15 words.
    Attribution: First name only.

Design note: Designer builds as animated GIF or stacked card visual. Each review is a
separate card that rotates or overlaps. Movement creates energy.
```

### UGC Photo Grid

A grid of user-generated photos with optional captions. The photos ARE the content.

```
Copy elements:
  Section header: Optional. (3-6 words)
  Per photo (3-6):
    Caption: Optional. @handle or short quote. Under 8 words.

Design note: Slightly imperfect, authentic-feeling grid. Not perfectly aligned. Can use
polaroid-style borders or Instagram-style frames.
```

### Press Logo Bar

A row of publication logos or names. Pure credibility signal. Almost zero copy.

```
Copy elements:
  Header: Optional. "As seen in" (2-4 words, or omit)
  Publications: 3-6 names or logos

Design note: Logos in grayscale or muted color. Small, evenly spaced. A thin strip, not a
section. Visual credibility accent.
```

### Numbered Callout List

Big bold numbers (#1, #2, #3) with short callout phrases. The numbers are oversized and
serve as visual anchors. Not a regular numbered list.

```
Copy elements:
  Per item (2-4):
    Number: "#1", "#2", etc.
    Callout: Bold statement or benefit (5-12 words)
    Body: Optional. 1 sentence expanding the callout.

Design note: Numbers are oversized (30-48px), bold, in brand accent color. They function
as visual landmarks. The reader's eye goes to the numbers first, callout text second.
```

### Social Media Screenshot Embed

A styled screenshot of a real social media post (tweet, Instagram comment, TikTok comment)
embedded in the email. Raw, authentic, unpolished.

```
Copy elements:
  Platform: Which platform the post is from
  Username/handle: The poster's name
  Post text: The actual post content
  Engagement: Optional. Like/retweet counts

Design note: Styled to look like an actual screenshot from the platform. Borders, platform
UI elements, profile picture placeholder. The "realness" is the point.
```

## Motion & Scroll Elements

These elements add visual energy and movement to break up static content.

### Scrolling Text Banner / Ticker

A thin strip with a repeating phrase that scrolls horizontally (or appears to as a static
GIF). High energy. Reinforces a single message.

```
Copy elements:
  Text: A single phrase, repeated. (4-8 words)
        "UP TO 50% OFF SITEWIDE" or "FREE SHIPPING ON ALL ORDERS"

Design note: High-contrast background. Text repeats 3-4x across the strip with separators
(dots, stars, pipes). Can be static with scroll illusion or an actual animated GIF.
```

### Scrolling Benefits Banner

Similar to the ticker but each repetition is a DIFFERENT benefit phrase. Creates a "wall
of benefits" visual effect.

```
Copy elements:
  Per benefit (3-6):
    Text: 2-5 words each.

Design note: Benefits separated by dots or icons. Scrolling or static. Can be single line
or stacked double line. Think trust badge strip with movement.
```

### Animated Product Reveal

A GIF that shows the product in use, being unboxed, or transforming. The animation IS the
content. Copy is just a caption.

```
Copy elements:
  Caption: Optional. 1 line below the GIF. Under 10 words.

Design note: GIF asset the designer creates or the brand provides. The copy doc specifies
what the GIF should show and any overlay text.
```

## Educational & Explainer Elements

These elements teach through visual structure, not paragraphs.

### How It Works (Numbered Steps)

3-4 steps shown as a visual sequence. Each step has a number, icon, and short description.
The visual progression tells the story.

```
Copy elements:
  Section header: "How it works" or similar (2-5 words)
  Per step (3-4):
    Step number: 1, 2, 3
    Header: What happens (3-7 words)
    Body: Optional. 1 sentence. Under 15 words.

Design note: Steps connected by arrows, dots, or a visual line. Horizontal on desktop,
vertical on mobile. Each step has an icon or small illustration.
```

### Ingredient Spotlight (Circular Icons)

A row or grid of ingredients/features, each shown as a circular image or icon with a name
and one-line description.

```
Copy elements:
  Per ingredient (3-5):
    Name: Ingredient name (1-3 words)
    Body: What it does. 1 sentence. Under 12 words.

Design note: Circular images (real photos of ingredients or abstract icons). Name in bold
below. Description in small text. Even spacing in a row or 2x2 grid.
```

### "Did You Know" Stat Card

A single shocking or interesting stat presented as its own visual card. The stat is the
headline. A 1-2 sentence explanation sits below in small text.

```
Copy elements:
  Stat: The headline number or claim (5-12 words)
  Body: 1-2 sentences. Context or source.

Design note: Bold stat text at display size. Dark or brand-colored card. The stat dominates.
Body text is secondary. Functions like a static ad dropped into the email.
```

### Process / Timeline Graphic

A visual timeline showing stages, phases, or progression. "Week 1 > Week 2 > Week 4"
or "Morning > Afternoon > Night" routines.

```
Copy elements:
  Per stage (3-5):
    Label: Time or phase label (1-4 words)
    Description: What happens (5-15 words)

Design note: Connected by a horizontal line, dots, or arrows. Each stage is a node on the
timeline. Icons or small illustrations at each node. Very visual, minimal text.
```

### FAQ / Myth Buster Cards

Individual cards that each address one question or myth. Each card is a self-contained
graphic with question on top and answer below.

```
Copy elements:
  Per card (2-4):
    Question or Myth: (5-12 words)
    Answer or Truth: (1-2 sentences)

Design note: Each card is visually separated. Can use "Myth" / "Fact" or "Q" / "A" labels.
Cards stacked vertically or in a 2-column grid.
```

### Routine / Usage Guide

Shows when and how to use the product throughout the day. Each time slot is a visual moment.

```
Copy elements:
  Per usage moment (3-4):
    When: Time or context (2-5 words, e.g., "After meals", "Before bed")
    What: What to do (1 sentence, under 12 words)

Design note: Each moment gets an icon or small illustration. Arranged as a visual timeline
or grid. Feels like an instruction card, not a paragraph of directions.
```

## Trust & Authority Elements

These elements build credibility through visual authority signals.

### Badge / Tag Strip

A horizontal row of 2-4 short credential badges. Each badge has an icon and a label.

```
Copy elements:
  Per badge (2-4):
    Icon description: Shield, leaf, checkmark, etc.
    Label: 2-4 words

Design note: Each badge is a small visual unit. Consistent styling. Pill-shaped, circular,
or rectangular. Sit in a row as visual trust signals.
```

### Guarantee Seal / Badge

A single prominent trust badge. Money-back guarantee, satisfaction guarantee, free returns.
Designed as a seal graphic, not text.

```
Copy elements:
  Main text: The guarantee (3-8 words)
  Supporting text: Optional. 1 sentence. Under 15 words.

Design note: Circular or shield-shaped seal/badge. Prominent placement near CTAs.
Functions like a trust stamp.
```

### Founder / Expert Quote Card

A quote from the founder, a doctor, or an expert. Photo + quote + credential. Built as a
card, not inline text.

```
Copy elements:
  Quote: 1-2 sentences. In their voice.
  Name: Full name
  Credential: Title or qualification

Design note: Photo of the person (headshot). Quote in italic or display font. Card format
with background color or border. The person's face adds human credibility.
```

### Certification / Testing Callout

Highlights third-party testing, certifications, or lab results.

```
Copy elements:
  Header: The certification (3-8 words)
  Body: Optional. 1 sentence context.
  Certifications: Names or logos of certifying bodies.

Design note: Clean, clinical feel. Logos of testing organizations. Can include a
simplified lab results table if relevant.
```

## Offer & Conversion Elements

These elements drive action through visual urgency or deal presentation.

### Promo Code Highlight Card

A standalone card showing a discount code. The code is the visual hero.

```
Copy elements:
  Offer context: What the code gives (5-12 words)
  Code: The actual code in caps
  Fine print: Optional. Where to use it. (under 10 words)

Design note: Code displayed large, in a dashed or highlighted box. Feels like a coupon.
The code itself is the visual centerpiece.
```

### Subscription Value Card

Shows the math of subscribing vs one-time purchase. Visualizes the savings.

```
Copy elements:
  Header: Subscription framing (3-8 words)
  One-time price: Standard price with strikethrough
  Subscribe price: Discounted price, highlighted
  Savings callout: How much they save
  Extras: Subscription perks (free shipping, gifts, etc.)

Design note: Single card comparing the two options visually. Subscribe side
highlighted/emphasized. Can include icons for subscription perks.
```

### Countdown / Urgency Visual

A visual countdown or deadline indicator. Creates time pressure through design, not words.

```
Copy elements:
  Header: The deadline or event (3-8 words)
  Countdown context: When it ends
  CTA: Action text (2-4 words)

Design note: Visual countdown clock graphic, bold deadline stamp, or progress bar showing
"almost gone" inventory. Urgency is visual, not just copy.
```

### Gift With Purchase Card

Shows free gifts included with purchase. Each gift is visualized with its value called out.

```
Copy elements:
  Header: Gift framing (3-8 words)
  Per gift (2-4):
    Gift name: What they get (3-8 words)
    Value: Optional. What it's worth.

Design note: Each gift shown as a visual with label and value. "FREE" tags on each item.
Feels like a bonus stack. Arranged in a grid or list.
```

## Usage Notes

### How Many Design Elements Per Email

A typical campaign email should have 1-3 of these design elements placed strategically. Too
many and the email feels like an infographic dump. Too few and it feels like a generic template.

Sweet spot: 1 strong design element in the top half (often in or just below the hero), 1 in
the bottom half, with standard copy sections connecting them.

### These Are Designer Specs

When you include one of these elements in a copy doc, you're writing a spec for the designer.
Label it clearly with the element name from this library so the designer knows exactly what to
build. Your copy fills in the text content. The designer handles the visual execution.

Example in a copy doc:
```
[Feature Checklist Matrix]
Columns: LarineCo | Regular Gum | Whitening Strips | Mouthwash
Row 1: Strengthens Enamel | Check | X | X | X
Row 2: No Artificial Sweeteners | Check | X | Check | X
...
```

### Skimmability Test

After writing a campaign, do the skim test: if someone scrolled through this email in 5
seconds and only their eyes caught the design elements (not the body paragraphs), would they
still understand the core message? If yes, the element selection is working.

### Mixing Elements with Standard Sections

These elements don't replace standard email copy (hero headline, body text, CTA). They
AUGMENT them. A typical email flow:

Hero headline/image > Short copy section > DESIGN ELEMENT > Short copy section > DESIGN ELEMENT > CTA

The design elements are the scroll-stopping moments. The copy sections are connective tissue.
